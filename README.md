## Usage

```bash
# Install dependencies (Express for potential server usage)
npm install

# Open any .html file directly in browser to view
# Or use a local server:
npx serve .
```

## Learning Path

1. **HTML/CSS** - Start with `html/` folder (37 lessons)
2. **JavaScript Basics** - `javascript/basics/`
3. **Functions** - `javascript/functions/`
4. **Arrays** - `javascript/arrays/`
5. **DOM Manipulation** - `javascript/dom/`
6. **Async JS** - `javascript/async/`
7. **OOP** - `javascript/oop/`
8. **Projects** - `javascript/projects/` (apply everything)
